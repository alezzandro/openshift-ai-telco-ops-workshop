== Hardware

Rehearsal starts with one Google Cloud `g2-standard-48` (4 × NVIDIA L4). The facilitator may run `./setup/scale-students.sh` to add three `g2-standard-24` (2 L4 each).

* Isolation is a **whole GPU**. NVIDIA L4 has no MIG.
* A 4-GPU stretch stays on the presenter 4-L4 node. A 2-GPU tensor-parallel deploy uses a whole 2-L4 node on class day.

HardwareProfiles:

* *NVIDIA L4 - 1 GPU* — default for P1, P2, P5–P7
* *NVIDIA L4 - 2 GPU tensor parallel* — P3 only, coordinate with the other tenant
* *NVIDIA L4 - 4 GPU tensor parallel* — stretch only; delete it immediately when done
* *CPU only* — workbenches in `{workbench_project}` only

== GPU courtesy

Never overlap two large services. Delete or stop your previous InferenceService before the next size class. Registry entries can stay. P10 Granite is 1 GPU; delete a 1-GPU deployment in your project first if you are at quota. The 2 GPU cap is OpenShift `ResourceQuota` `gpu-quota` on your project (not an OpenShift AI Settings quota). Hardware profiles only size *one* deploy.
