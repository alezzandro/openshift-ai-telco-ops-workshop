== Hardware

Rehearsal (`full-setup.sh`) is **one** Google Cloud `g2-standard-48`:

* 4 × NVIDIA L4, 24 GB each (96 GB total)
* Label `node-role.kubernetes.io/worker-gpu` and `workshop.opendatahub.io/l4-count=4`
* Taint `nvidia.com/gpu=True:NoSchedule`

Class day (`./setup/scale-students.sh`) adds three `g2-standard-24` (2 L4 each; 10 L4 / 240 GB total). Do not add a second 4-L4 node.

NVIDIA L4 has **no MIG** and **no NVLink**. Isolation is a whole GPU. Tensor parallelism on this shape uses NCCL over PCIe.

Packing: on the rehearsal node, C3+C4 share it; C6 2-GPU tensor parallel uses half; a 4-GPU stretch consumes the whole node. On class day, C6 uses a **whole 2-L4 node**; the 4-GPU stretch stays on the 4-L4 node.

HardwareProfiles in the dashboard:

* *NVIDIA L4 - 1 GPU* — catalog and quantized models
* *NVIDIA L4 - 2 GPU tensor parallel* — set `--tensor-parallel-size=2`
* *NVIDIA L4 - 4 GPU tensor parallel* — whole node; playground stretch only
* *CPU only* — workbenches so a notebook cannot steal an L4
